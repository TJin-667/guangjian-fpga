# 上位机入口与采集

**公开快照前置：** 本页的完整工程流程须先按[外部依赖说明](external_dependencies.md)合法取得并恢复原 IP、板级文件和工件。直接克隆的公开快照只保证独立离线胶囊入口；缺少外部文件时原完整性检查会拒绝运行。


先按[离线说明](quickstart_offline.md)安装依赖。在仓库根目录运行：

```powershell
& ./.venv/Scripts/python.exe -B scripts/launch_gui.py --check-only
& ./.venv/Scripts/python.exe -B scripts/launch_gui.py
```

第一条只检查依赖与资格，成功状态为`SPEED_UI_OFFLINE_READY`；第二条打开窗口。打开窗口不会下载bit、改变网卡、采集图像或点亮光源。实际硬件操作需要在窗口中明确启动。

## 数据目录与设备端点

默认输出位于仓库`_work/data/`。推荐设置到空间充足的数据盘：

```powershell
$env:GUANGJIAN_DATA_ROOT='E:/GuangjianData/SubmissionRuns'
& ./.venv/Scripts/python.exe -B scripts/launch_gui.py
```

也可复制`configs/runtime.local.example.json`为`configs/runtime.local.json`，修改`data_root`及`network`。本地配置不进入提交版本；默认配置和代码仍受完整性校验。应用默认端点为板卡`192.168.0.2`、电脑绑定`192.168.0.3`、UDP端口5000。这些值只是应用端点，工具不修改操作系统网络设置。

数据目录不能设置为源码、样例、凭据或报告目录。采集后的PLAN、会话记录会绑定当次真实路径；不要直接改写它们来冒充新的采集或姿态确认。

## 使用流程

1. 使用已验证的板卡位流，连接相机、四路光源及以太网。提交副本不自动下载或切换位流。同一时刻只运行一个板卡采集程序。
2. 输入样品名和面/阶段；默认低/高曝光400/800行，gain16=16、LED128。400/800来自多轮开发对照，允许针对实际工件人工微调；组内参数固定并逐帧读回。
3. 手动调焦：预览目标2帧/秒，上限1000帧，可拖框选择清晰度区域并缩放查看。该指标用于同场景、同区域、同光照下调焦；预览不算正式八帧。
4. 新摆放时重新定位，按窗口确认四角及外扩像素。保留原坐标裁剪，不做透视取正。定位帧不算正式八帧。
5. 开始下一组：按CH1至CH4顺序，每方向低/高曝光各一张，共8张正式帧。保持工件、相机及灯位不动。采集后执行冻结检测与局部复检，分别保留结果和来源。
6. 同一摆放下可改样品记录或曝光后继续下一组，复用已确认的ROI/mask。工件移动、板卡复位、会话失效或姿态不确定时，按状态提示重新建立定位/会话。

CH1为检测台内侧前方，CH2右侧，CH3开口侧后方，CH4左侧。调焦、定位、等待、丢弃和失败重试均有独立工程记录，不冒充额外正式样本。

本次提交适配已进行离线资格、控件和数学复现核查；原冻结版本的实板记录保留作为硬件证据。提交路径适配后的新实板全流程若未另有记录，不宣称已经重复完成。
