# 竞赛提交内容与仓库对照

适用 AMD 2026 自主选题 §3.3。指南推荐目录结构可调整，完整工程、验证、报告、协作记录和技能包按实际采用的实现方式提交。项目采用 RTL 与外部 PC，不增设未采用的 HLS、PS 或 PYNQ 文件。

| 指南内容 | 本仓库对应 | 核对重点 |
| --- | --- | --- |
| `README.md` | 根 README 和 `docs/` | 项目、版本、环境、复现入口、实际范围。 |
| `src/` | FPGA、主机及冻结算法自研执行树 | 含仍调用的历史模块；受限第三方原件按外部清单恢复。 |
| `sim/` | RTL、软件、离线验证和结果 | 工具、输入、源身份与比较方法。 |
| `build/` | `src/fpga/implemented/`、`scripts/build_fpga.py`、`board/results/` | 按实际输入/脚本/报告分开组织，构建产物放忽略的 `_work/`，不重复一份工程。 |
| `board/` | 硬件说明、脚本、工件及实板结果 | 真实 bit 身份、接线、参数读回与资格边界。 |
| `data/` | 完整代表样例和配对参考 | 核心回放输入随交付提供；区分 0108 回放与 0109 板测。 |
| `skill/` | 普通主机分段计时工具 | 独立示例、适用范围、失效条件、来源及验证。 |
| `report/` | 正式报告、证据、媒体与 AI 记录 | 报告唯一版本、真实摘录、人工决策和未交内容。 |

报告基准为 2026-11-02 的 46 页 mask 存储修订稿，详见[报告说明](../report/README.md)。四份运行文档、工程可公开部分和报告原件已经合入，路径按实际目录核对。230 项外部原件及既有 bit 不在公开包内，完整硬件流程的前置条件见[外部依赖](external_dependencies.md)。报告中原私有来源与本仓库的对应见[公开证据映射](public_evidence_map.md)。

## 平台独立上传项

用户提供的上传页面要求 GitHub 链接、全部代码 RAR（200 M 内）、技术报告 PDF（50 M 内）、MP4 AVC/H.264 演示（3 分钟内、300 M 内）、承诺及授权书 PDF（50 M 内）；海报为选填 PDF/PPT（50 M 内）。全貌照片最多 1 张、开发板照片最多 4 张，JPG/PNG 每张 10 M 内。

代码 RAR 与 GitHub 使用同一固定快照。签字授权书按平台单独管理，不自动公开。报告与视频按页面要求避免学校、指导老师等无关信息；海报保留经确认的署名与校徽。上述格式要求来自上传页面，不全部归于指南正文。

正式 Release 的 RAR 与 Git 快照一致，附件提供字节数、SHA-256、解包清单比对与离线回放结果。公开包包含自研源码与外部依赖清单；若赛方要求额外交付受限原件，须取得对应权利并确认交付方式。GitHub 链接不能替代平台的独立上传项。最终演示 MP4、签署授权书和 XDL 本轮真实 AI 协作记录尚未随本发布交付。
