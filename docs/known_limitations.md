# 已知限制与使用边界

本系统输出划痕候选和人工复检线索，当前不提供自动合格判定。

- **缺陷覆盖。** 弱段增强、端部补充和局部复检受已有种子、结构及准入条件约束。没有种子的整条弱线、未观察到的响应仍可能漏过。H/M 优先级及证据分不能解释为划痕概率。
- **已知误提示。** 006 后态 R1 的 M45 已确认是油污或纹理等非划痕，保留为误提示。006 前态 H70 尚未裁决，不擅自补标签。
- **样本独立性。** 25 组开发回归来自三块板，重复拍摄和组数不能算作独立工件数；006 只有一块冻结后补充工件。没有完成独立、多工件、完整真值的准确率评估。
- **成像条件。** 400/800 行是推荐默认，并非所有材质与姿态的最优值；需要人工调焦、ROI/mask 确认及必要的组间曝光调整。组内固定并读回，程序不自动旋转取正或自动调曝光。
- **硬件资格。** 0109 内部时序和已测功能有记录，但外部 DVP/RGMII 完整电气/延时签核、位流 SHA 的硬件读回验证和生产发布资格尚未完成。使用既有 bit 时保留原实验状态和身份凭据。
- **速度结论。** 旧完整任务 A/B 中 PL 协作路径更慢；15.35%～17.05% 是特定软件区间改善，1.0328 是另一段主机中位比值。新版整机 A/B、纯 FPGA 核加速和实测功耗仍未知。
- **复现层次。** 004 离线案例来自旧 0108，只验证冻结数学与配对结果。它不能代替当前 0109 采集、GUI 异机迁移、物理 DDR 或外部 IO 验证。目录迁移后以实际发布记录说明通过了哪些步骤。
- **演示对照。** 006 低/高/八帧对比是同组固定 B1 的曝光消融；004 弱段增强与另一组复检分属不同案例。四灯全开历史画面的 300 行曝光及姿态边界不能用于严格同输入加速或精度结论。
