# 接线与灯位定义

前后命名以已确认的箱体视角为准：靠箱内里侧为前侧，靠开口为后侧。

| 通道 | 灯位 | 正式观测顺序 |
| --- | --- | --- |
| CH1 | 靠里前侧 | slot 01 低曝光，02 高曝光。 |
| CH2 | 右侧 | slot 03 低曝光，04 高曝光。 |
| CH3 | 靠开口后侧 | slot 05 低曝光，06 高曝光。 |
| CH4 | 左侧 | slot 07 低曝光，08 高曝光。 |

各组还有 1 张准备帧，不能将它计入正式八帧。通道是控制/采集身份，不能只凭照片朝向交换编号。重复采集须核对实际曝光、增益、LED 值和帧身份。

## 接口关系

| 连接 | 已确认用途 | 进一步核对 |
| --- | --- | --- |
| OV5640 → FPGA | DVP 像素/同步输入，SCCB 配置。 | 排线方向、引脚、电平和相机供电按实际板卡接口及 XDC 核对。 |
| FPGA → 四路照明控制 | 逐方向灯控，与相机曝光计划配合。 | 驱动板型号、实际引脚及负载电气规格由工程集成清单补齐。 |
| FPGA ↔ 外部 DDR | 原片、scratch、融合 bank 工作存储。 | 板级 DDR 与 IP 配置随正式工程，不按照片重新布线。 |
| FPGA ↔ PC | 开发板左侧黑色以太网线。 | 真实 IP、端口、网卡和协议设置见最终上板/协议文档。 |
| 电源 → FPGA 板 | 开发板右侧白色供电线。 | 先确认板卡资料与电源铭牌，不从线色推断电压或极性。 |

以上是逻辑接线说明，具体 FPGA 管脚、时钟和 IO 电气标准以发布工程的 XDC 为准。外部 DVP/RGMII 完整 IO 资格仍未完成，不能据内部时序通过推断所有接口已签核。
