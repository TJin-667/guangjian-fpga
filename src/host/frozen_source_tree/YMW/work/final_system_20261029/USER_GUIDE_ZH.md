- **正式帧保存**默认“RGB+灰度审计”；“灰度证据候选”保留8张真实gray/SAT，减少重复RGB负载，先用一组实板确认后再决定默认值。改变格式新建计划，原ROI/mask与旧计划不改。
- **采后每次完整重算核验（较慢）**不勾选时，可复用同一份已经完整验证且源哈希、原生planes逐字节一致的证据。首次采集仍严格核验。缓存损坏不会被当成有效数据；需要时可勾选完整复核。
- **性能分段记录**显示输入复核、冻结算法计算、报告等主机区间。嵌套区间不累加，服务时间不等于FPGA器件周期。
- 采集成功后自动保留CAPTURE_PERFORMANCE、PERFORMANCE和END_TO_END记录。点击到分析归档区间排除之前定位/人工和之后UI绘制。
- 新实板组完成后运行E盘同目录 **RUN_AFTER_CAPTURE_ANALYSIS.cmd**，只读最新组，生成同输入PC参考和10项数组/复检/分数核对。它不联系板卡；最新组失败或缺计时会明确报错，不使用旧组替代。

一次实板步骤见[最小清单](../performance_closure_20261030/BOARD_WINDOW.md)。无需为本软件更新重新下载0108。

# 光鉴一体化入口 v1.5 使用说明

## 启动和版本

正常退出旧窗口，再双击桌面 **光鉴0108新入口.cmd**，或运行 `E:/GuangjianData/software/FinalSystem_20261029/RUN_0108_SYSTEM.cmd`。确认标题显示 **v1.5 · f09eb5885e1d**。本次更新不需重新下载bit；继续使用当前0108工程bit。

当前算法：400/800行、gain16=16（1倍）、LED128；检测补充弱5.2/强12；复检原片支持55%、端点线形28%。检测补充本身的线形门槛仍60%，这三个比例属于不同环节。界面不开放算法阈值编辑。

如果板卡实际仍是0107，使用同目录 `RUN_FINAL_SYSTEM.cmd`，不要用0108操作台操作0107。只查看结果或分析已有数据无需连接板卡，启动核验也不查询板卡。

## 继续采集

1. 在0108操作台填写样品名和面/阶段。样品名与采集参数沿用原入口的设置能力；正式流程固定400/800、1倍和LED128。
2. 需要调焦时点“0108实时调焦”：目标2帧/秒、上限1000帧；鼠标框选清晰度区域，滚轮缩放、拖动查看。调焦完成后停止并等待关灯记录收尾。
3. 摆放已改变时，点“新摆放：1张定位并准备计划”。在原图页确认轮廓/余量和ROI，生成计划。定位图不计入正式八帧。
4. 保持摆放，开始八帧工程采集。现有0108在BEGIN前还需1张ROI准备帧，由入口自动完成并单独归档，不混入正式八张。
5. 成功后自动运行新冻结算法，切到“最终检测 / 复检”。采集失败或取消的组不会自动分析。不要仅为本次软件更新重复已做过的采集和bit检查；下次正常采集即可顺带确认新入口闭环。

0107模式沿用原调焦→定位/ROI→八帧流程，勾选“采集成功后自动检测并复检”即可使用同一新算法。

## 处理已有照片

在“最终检测 / 复检”中：

- **打开已有采集并检测**：选择完整GUI采集目录或pair目录，自动完成B1输入准备并用当前算法处理，无需重拍。
- **打开已有B1结果并处理**：选择含summary.json的完整B1Detection目录。
- **导入0108实板结果**：选择已通过八帧工程采集的fusion目录。完整身份、实际参数、原生图、R32及关灯收尾仍严格核验。
- **重开一体化结果**：只查看原来保存的结果。旧4c0结果会标为“历史版本（非当前冻结）”，不会自动重算或冒充新版本。

实验曝光可离线处理，会保留实际曝光并标为实验。它不替代400/800正式参数。

## 查看检测和复检

左侧选择黄色检测、橙框结果、八张原片或复检局部；右侧支持适应窗口、100%、滚轮缩放和左键拖动。点击复检表中的一行可查看对应局部，点“详细报告 / 人工复核”查看来源原图和填写复核记录。

黄色表示正式检测。橙框表示疑似还存在漏段，建议人工查看原片；证据支持分是规则刻度，不是正确概率。无框不自动判合格，橙框也不会自动补画黄色划痕。

## 保存位置与备份

原片仍在E盘P0Pairs或final0108_positioning体系，结果默认在 `E:/GuangjianData/UnifiedInspection/时间_标识/`；不覆盖输入或旧检测结果。

每份新结果含JOB.json、RESULT.json、OUTPUT_MANIFEST.json、日志以及final/报告。RESULT标记 `parameter_freeze_id=f09eb5885e1d`；final内保存FROZEN_PARAMETERS/FROZEN_SOURCES的原始快照。快照中“当时尚未接入”字段保留冻结时记录，实际接入版本以RESULT及当前STATUS为准。人工复核记录按新组合隔离保存，不继承旧结果的结论。

更新前v1.3源码、部署入口、桌面CMD和bit已备份到E盘software/backups，位置与逐成员SHA见 `YMW/work/frozen_algorithm_integration_20261030/BACKUP.json`。原09、r5.6和旧bit保留。

## 停止、失败和剩余验收

停止分析只取消本入口拥有的离线进程，保留原片。采集停止或关闭窗口时应等待取消/关灯收尾，不强行结束进程。出现失败时保留日志，不接着向失败组补写新帧。

已有0108真实八帧同输入功能对照仍有效。本次接入另用已有003/004/005和真实0108归档核验结果一致；没有新采集或硬件操作。后续仍需接口/复位发布资格、预留工件评价，以及用户已延后的PC/FPGA性能对照；这些不因软件参数冻结而自动完成。
