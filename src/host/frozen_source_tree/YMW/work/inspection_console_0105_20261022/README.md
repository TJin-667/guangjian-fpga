# 09：YMW统一采集与四方向融合控制台

把已完成的定位、四方向采集和XDL冻结融合算法接成一个操作入口，便于整机演示和后续独立样件实验。新增09，原01～08、预览、controller-0.1、RTL和bit保持原样。无需重新下载bit。

## 功能范围

| 入口/模式 | 具体行为 | 证据边界 |
| --- | --- | --- |
| 离线查看已有四方向ZIP | 校验库存、SHA、帧身份、参数读回、RGB565/PNG像素、CRC64及H1/H2；计算B1/M1，显示原图和候选 | 重算旧实拍，当前运行不连接板卡 |
| 固定600行 | 从本轮02/03继承真实样件编号、ROI和内缩mask，重新采CH1上→CH2右→CH3下→CH4左 | 等待本人验证09真实执行；原08已有实拍 |
| 本轮自动曝光后采四方向 | 先调用原07；本轮LOCKED且独立审计PASS、同样件/来源/mask匹配和关灯ACK后，继承400/500/600/700中的锁定档；再独立新采四图 | 不把离线LOCKED或调参图当作新的正式观测；新09串联待实板验收 |
| 查看与保存 | 四方向原图、B1简单MaxAbs、M1质量约束、无有效观测图、候选连通区域坐标CSV、逐像素NPZ、过程/成本和完整ZIP | 候选连通区域数不等于划痕条数；不输出合格率、物理深度或最优曝光 |

灯光固定LED128、增益16=1×。曝光单位为行。四张正式图共用曝光/增益/几何；不搜索亮度和增益，不启用M2少拍策略，不执行XDL新的弱线实验，不向检测器输入S1/S2手工参考线。没有把电脑端融合宣称成FPGA部署。

## 本机入口

`C:/BX72_0105_LAB/09_inspection_console.cmd`，安装目录`inspection_console_v1/`。详细步骤见同目录`OPERATOR_STEPS.txt`。

先用“离线查看已有四方向ZIP”打开10月20/21日的001或002数据，看图和结果。离线不需要连接开发板，也不需要调整VPN。

实际拍摄时，本人确认供电并按原方法处理VPN。换工件、移动相机/灯位/工件或重新上电后，先02输入真实编号并定位，再03确认裁剪。09会拒绝最新03与02不匹配，且不会回退到旧样件。关闭预览，检查轮廓并勾选摆放一致后才点击开始。首轮先用固定600行模式。

所有采集在工作线程中，融合在独立CPU子进程中；主线程只更新界面。停止/关窗会请求取消，采集器尝试关灯并保留部分记录。02/03/06在本人操作的独立控制台运行，需在其窗口按提示退出，09不强行终止它们。通过09启动的这些旧程序额外受采集锁保护；单独从资源管理器启动的旧预览仍需本人关闭。

原图保存像素不缩放；界面缩略图仅供预览，点击可按100%像素滚动查看。红色仅为算法候选；洋红为全部光向都缺少有效观测的板面；橙色为至少一光向任一RGB通道达到最大码的风险，不表示三通道都过曝，也未直接删除这些像素。

## 接口与算法来源

- 冻结08脚本SHA256：`d0a537d7cf0a336bb93a8b1d6f4270430e0032d326c77ca699c79dbdecb2fd6d`。
- 冻结07 r3核心SHA256：`448fa6c6388093be794cf47f4932e77b688da92f74aa852ba8609b2cf5992857`。
- XDL融合版本`fourlight-fusion-1`，来源提交`d5be1ed8da364d43e5e5860b934c39ef7487fd2d`，运行时9个文件逐字节保留，见`vendor_manifest.json`。原完整`freeze.json`仅作来源说明，未捆绑其全部评价/标注脚本。导入前核对冻结文件，不修改其算法。
- 灰度整数公式、9×9 REFLECT_101、残差分母81、严格阈值648/1620、质量分块及并列规则沿用XDL；滤波在整个保存ROI上算，最后与几何板面mask相交。未将mask外像素先置零。
- 新通用适配器面向任意样件编号；不绑定001/002的参考标注。身份计数按协议位宽检查向前推进，容许合法回绕。图像字节恰好相同不能单独证明复用，必须结合独立采集身份/参数/CRC/原始记录核验。
- H1分母是上传内缩mask；质量无效/unknown另存，不能换成02原多边形分母。全画面common与ROI局部native都必须为0/1且逐像素对应。

## 输出与成本

在线：`results/inspection_online_样件_时间_随机号/`；离线：`inspection_offline_.../`。每次新建，拒绝覆盖旧结果。

在线输出含`acquisition/`的原图、RGB565、committed记录、读回、统计、trace及内层库存；`analysis/`含B1/M1 NPZ/候选图/风险图/CSV；外层汇总状态、所有阶段成本和校验库存。自动曝光模式额外嵌入原07 ZIP的完整字节并登记SHA，原07结果仍独立保留。

四次完整采集已知事务成本为20帧：每次1等待+3丢弃+1保存，不能只报告4帧。自动曝光试拍、传输重试、失败、mask上传、分析和压缩开销另存。02/03为之前独立初始化，不计作正式四图或假装已包含在本轮计时；原07模型成本与硬件事务口径仍有区别。ZIP附件记录主机截至归档完成的耗时，尚不能证明物理稳定等待或完整生产节拍已标定。

外层归档沿用07的临时ZIP→解压逐文件核验→发布→SHA/receipt方式。归档失败保留原目录；只有关灯ACK不等于实物已经熄灭。
