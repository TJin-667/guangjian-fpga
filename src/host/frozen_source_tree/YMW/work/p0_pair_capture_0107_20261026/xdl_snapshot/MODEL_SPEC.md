# XDL 低/高曝光四方向条件证据融合方案

日期：2026-10-26  
用途：软件实验规格；供 YMW 准备 P0 真实配对采集，供 TJ 配合标注。  
状态：**模型结构在本轮冻结为实验候选；参数、验收阈值与真实收益尚未验证。**

## 1. 决策摘要

保留现有划痕检测核心、B1、controller-0.1、采集程序和 RTL。建立独立的 `exposure_fusion_v1` 实验流程，处理同一实体板、同一面/版本/姿态、同一会话和固定成像条件下的低/高曝光图。

主候选定为**少参数、按局部成像质量变化的条件曝光门控**。它融合现有 H2 残差产生的正、负（亮、暗）划痕证据，不从零训练大型分割网络。四个光向各自先融合低/高曝光，再按原方向 Max 规则合并；每处输出亮/暗证据及其方向、曝光来源。

这冻结的是软件实验结构，不是已拟合模型或产品检测器。首批 400/800 行只是待验证曝光对，不宣称最佳曝光。只有完整 P0 数据、人工复核标签和板级验证后，才决定条件门控是否优于简单基线。

## 2. 为什么选这条路线

- 本任务需要保留金属板上的细弱划痕，且反光、高光、亮线与暗线并存；自然场景多曝光融合的“观感更好”不是合适目标。
- 当前每实体板的独立样件很少，整条路径/背景人工标注也有限。训练大 U-Net/Transformer 容易记住板面、姿态或高光纹理，且难以证明泛化。
- 已有 H2 和亮/暗分离证据、四方向融合和带来源的结果输出。门控只增加三个共享标量，容易做消融、审查和后续定点化。
- 同一曝光组中，一档可能保住近光细节，另一档可能补远端弱段。局部门控允许按观测质量互补，不假定全图一个固定比例，也不要求划痕必须同时出现在两档或多个光向。

## 3. 冻结的数据与特征约定

### 3.1 输入边界

一个完整配对组包含同一物理板、面/版本、固定姿态、会话、采集轮次和重复号下的 8 个不同实拍帧：`CH1..CH4 × {low, high}`。P0 固定 `gain16=16`（1×）、`LED=128`，暂提 `low=400` 行、`high=800` 行；YMW 需确认 0105 RGB 固件确实接受这两个值并逐帧记录写入/读回。若任一档不合法，先暂停该批并回报实际约束，不能私自换档或拿不同轮次数据拼组。

所有帧保留原图、源 SHA、真实硬件帧身份、实际曝光/增益/灯向、ROI、valid mask、帧发布/CRC 信息。每组曝光变化必须发生在拍摄同一静止姿态期间。确认新帧身份和参数读回后再把帧纳入组。不同组、不同姿态或不同曝光扫描轮次不得混拼。旧的单曝光四向图及 004 CH1 参数预览只能用于调试、标签准备或单图诊断，不能补成低/高配对帧。

### 3.2 既有特征抽取

不修改冻结的整数参考及当前 H2。对每张保存的 ROI `gray8` 使用 `software/ymw_integer_reference.py` 的 H2 残差（当前融合代码在保存 ROI 上调用 `integer_h2`）。每个 32×32 tile，以 valid 且非 SAT 像素计算

`s_e(t) = max(1, 1.4826 × MAD(gray8_e(t)))`

`r_e(x) = residual_n_e(x) / (81 × s_e(t))`

已有证据定义为：

`E_e,+ = clip(max(r_e, 0), 0, 255) × ρ_e(t)`  
`E_e,- = clip(max(-r_e, 0), 0, 255) × ρ_e(t)`  
`ρ_e(t) = max(0.15, 1 − SAT_fraction_valid(t))`

正、负证据一直分开。MAD 是局部对比尺度代理，不称为相机时域噪声或实测 SNR。SAT 表示任一源 RGB 通道达到最大码的风险；它不意味着把所有这些像素直接删除。

**饱和可靠度只用一次。** 当前 `features.extract_evidence()` 已将 `ρ` 乘进 `bright/dark`。因此门控后的融合是 `q_L E_L + q_H E_H`，不得再乘一次 `ρ`。门控特征本版不再把 SAT 比例作为输入，避免同一饱和信息被再次惩罚；结果仍并列输出每档的 SAT 风险图。

### 3.3 两个预注册门控特征

每个曝光、方向、tile 只从同帧图像和 valid mask 提取质量特征，不读标签、scratch 坐标或候选结果：

1. `z1 = (P10(gray8_H, valid) − P10(gray8_L, valid)) / 255`，tile 内只对非 SAT 的 valid 像素取 P10。它表达暗部/低分位亮度变化，不是平均亮度目标，也不是“越亮越好”。
2. `z2 = log((s_H + 1) / (s_L + 1))`，表达当前局部稳健对比尺度的相对变化，不宣称噪声改善。

每个训练折只用训练板计算 `z1/z2` 的均值和标准差；该变换冻结后应用于对应验证板。标准差为零时该特征在该折置零并记日志。若 tile 任一曝光没有非SAT有效像素，或两项特征不可计算，则该 tile 门控回退到 `q_H=0.5`，并标记为需复核；不能把缺失质量统计伪装成正常的零差异。若 valid mask 本身为空，则该区域没有可评价证据。禁止利用验证板或测试板估计归一化参数。

## 4. 条件门控与方向融合

对所有方向、亮暗极性共享同一组门控参数：

`q_H(d,t) = sigmoid(b + θ1·z1(d,t) + θ2·z2(d,t))`  
`q_L(d,t) = 1 − q_H(d,t)`  
`F_(d,p)(x) = q_L(d,t)·E_(L,d,p)(x) + q_H(d,t)·E_(H,d,p)(x)`

其中 `p∈{bright,dark}`。同一组 `q` 应用于同一 tile 内两个极性，避免为了追着已知划痕把某一极性单独调成高权重。门控 tile 值在相邻 tile 中心间做双线性插值，减少硬边界；tile 边界单独检查伪线和候选跳变。

随后按照当前 `fusion.py` 的 Max 方向策略分别计算 `F_bright=max_d F_(d,bright)` 与 `F_dark=max_d F_(d,dark)`，用于路径评分的汇总 `score=max(F_bright,F_dark)`。输出每像素最佳方向、亮暗极性和低/高来源。来源图用于追溯，不当作真值。

门控参数只有 `b, θ1, θ2` 三个；权重是“融合贡献比例”，不是划痕概率、置信度或质量放行概率。用有限网格拟合：对训练折标准化后的三个参数在预注册小网格 `{-2,-1,0,1,2}` 搜索（125 种），并把 `(0,0,0)` 作为等权锚点；按验证目标选择，平分时优先最接近等权、背景响应较低的组合。网格和特征清单先冻结，不因测试结果扩网格。

目前 `training.py` 只支持每实体板一组及全局 `high_weight + threshold`，且背景约束为开发板均值。**条件门控和多组训练入口还未实现**。拟合前需扩展 group_id 级标签、多组/同板加权、板级约束与折内归一化；不能用现有全局 `fit` 冒充条件门控结果。

## 5. 必须保留的对照与验收方法

完全同一批 8 帧、同一 ROI/valid mask、同一标签和同一划痕参考下比较：

| 方案 | 用途 |
| --- | --- |
| low-only | 四个方向都只用低曝光；显示低曝光单侧证据 |
| high-only | 四个方向都只用高曝光；显示高曝光单侧证据 |
| equal-weight | 每方向固定 0.5/0.5；简单融合基线 |
| learned-global | 现有全局 high_weight 拟合；控制增加门控特征后的增益来源 |
| conditional-gate | 本规格的主候选，3 参数共享局部门控 |

报告两类结果：①固定阈值消融，观察只改融合规则的变化；②每方案只在训练折内选阈值，在同一验证板和同一人工确认背景风险约束下比较。背景风险上限、标注容差/站点间距、弱尾可接受退化量必须先在 P0 人工审阅后写入冻结配置，再开始正式拟合；**当前没有确定数值，不得照搬示例 5%**。

主要指标按实体板、组和划痕宏平均报告整条/分段/weak-tail 参考站点支持率、最长缺口（站点数及约定站点间距换算像素）、确认背景响应率、最差板结果、unknown/无效观察比例、门控图与证据来源，以及试拍、初始化、等待、丢弃、重试、确认和推理的完整成本。候选像素更多不是收益；未标候选不是自动误报；sample002 仅为“近似无缺陷”开发样件，不是严格正常真值。仅四个方向都只有单组时，数据不足以验证重复稳定性。

不接入 007–010，不据此选特征、门槛、模型或可靠性规则。模型/标签/曝光/阈值/可靠性规则冻结后，另行对其做一次最终测试；若看过测试并据此调参，它们就不再是盲测。

## 6. 数据拆分和标签

- 物理板是唯一 train/validation/test 分组单元。该板的 A/B 面、v0/v1、所有姿态、重复、裁块和增强数据必须跟随同一折。
- 开发样件 001–006；007–010 整板冻结留出。当前交接确认 001–005 主面已完成，006 尚待完成，因此现阶段真实样本数按实际五块写，不能宣称完成六板验证。六板齐全后按 YMW 计划做 3 折 GroupKFold，每折 4 板训练/2 板验证；不足六板则明确实际分组和折数。
- 标签用 `annotation_schema.json` v2，全图 `1920×1080` 坐标，绑定 `group_id`/板/面/姿态/轮次/重复/源 SHA；保留 scratch_id、whole_line/segment/weak_tail、确认背景、unknown 和端点状态。YMW负责实物划痕归属及疑难裁决，TJ协助描线和整理，XDL负责schema、坐标转换、valid-mask质检和训练评估。
- 先独立于算法结果看原图标参考，再叠候选核查。真线不因模型没找到而降成 unknown；不确定部分继续标 unknown；未标区域不自动算背景。标签只进 fit/evaluate，不进入 infer。

## 7. 外部方案借鉴，不直接照搬

| 方案 | 适用借鉴 | 为什么不作为本轮主模型 |
| --- | --- | --- |
| [MEFLUT（ICCV 2023 官方实现）](https://github.com/Hedlen/MEFLUT) | 多曝光分支与小型 LUT 的低成本部署思路；后续可把冻结门控量化成查表实现 | 其目标是自然图像视觉质量，官方实现依赖旧 PyTorch/CUDA 与专用数据；并非划痕线证据监督或本板材验证 |
| [MEF-Net 官方实现](https://github.com/makedede/MEFNet) | 低分辨率预测融合权重、引导滤波上采样可作离线空间权重参考 | 训练目标是 MEF-SSIM 观感指标，依赖旧 PyTorch；不是金属缺陷完整性/背景约束 |
| [DeepCrack 官方实现](https://github.com/qinnzou/DeepCrack) | 层级/多尺度线状特征、细线连续性设计思路 | 数据域为道路裂缝，本项目不能直接沿用其模型权重或道路语义；当前样件量也不足以从头训练大网 |
| [PatchCore 官方实现](https://github.com/amazon-science/patchcore-inspection) | 将来若有覆盖足够的严格正常板，可作单独无监督异常定位对照 | 当前没有严格正常真值，002不是严格正常；异常热图也不直接给可靠划痕路径 |

结论：借鉴 MEFLUT 的轻量化思想和 DeepCrack 的线结构视角，保留现有 H2 证据域，先验证三个共享标量的条件门控；不把文献报告的速度或视觉质量当作本项目收益证明。

## 8. 7A100T 迁移边界

此方案先作为电脑端软件参考模型。三参数门控本身可做定点乘加加 sigmoid LUT（或直接离线导出量化权重表），但其输入特征的 tile P10/MAD 计算、ROI处理、同步八帧存储和已有证据提取的资源/时序成本尚未审计。只有软件方案在独立板级验证有收益后，TJ再评估把哪些统计放在电脑、哪些特征与融合下沉 7A100T，做定点逐像素对照、资源和时序评估。**当前没有 FPGA 模型部署或闭环结果。**

## 9. 下一阶段门槛

1. YMW确认 400/800、gain16=16、LED128 可写且读回、完整身份/CRC可记录。
2. 完成 2 组必需的完整八帧真实配对；至多第 3 组，不要求一次采满 100 组。
3. TJ/YMW交人工复核标注，XDL冻结背景风险上限、容差、弱尾保护和停止条件。
4. 实现多组/板级分组和条件门控，再做折内训练与固定阈值/同背景预算对照。
5. 只有条件门控在多个开发板上稳定保住弱尾、背景不恶化且可靠性理由可解释，才保留它；否则选择简单且已验证的 equal/global 方案并保留负结果。
