# 光鉴r5.6：通用样品与本轮曝光设置＋调焦卡顿修复

## 本轮设置

- **样品名可输入**：例如sample006、plate_A01，不限004/005；支持1～64个英文字母、数字、下划线、短横线，首字符为字母或数字。此限制与既有采集身份协议一致；不接受路径、空格、中文或Windows保留名称。同一块物理板请保持同一个名字，面和阶段另选。
- **面/阶段**：A_v0、A_v1、B_v0、B_v1，也可输入同格式的新版本。v0是新增划痕前留底，v1是制作后；软件不判断实物制作状态，按实际选择。
- **低/高曝光可输入**：默认400/800行；均须为1～1116的整数，低＜高。范围来自现有0107严格SDK的参数限制，不是最优曝光结论。增益仍固定1倍、LED128。
- 定位与调焦曝光取两值的整数中值：400/800对应600行；320/960对应640行。调焦界面显示实际读回参数。
- 点击开始时冻结样品、面/阶段及曝光；运行中输入框禁用。四方向各低/高一帧，八帧实际请求、读回校验、归档、对比标签与XDL清单使用同一套参数。非法设置在创建采集任务/联系板卡前提示。

输入框只用于下一轮；离线打开旧组时，原图列表和标签按已归档的实际参数显示，不因输入框改变而重命名旧帧或改写原始数据。
