# 0107独立工程验收的资格边界

本轮收尾固定八请求入口、同一冻结硬件输入对照、共同复位和接口资格。现用09和0105/0106原bit保留；没有追加背景相减回传、阈值、压缩或融合算法。

## 已有证据沿用

0106小ROI及1920×1080的RGB565、GRAY8+SAT1真实负载、实际CRC64、H1/H2、身份和关灯ACK已经通过；原四张工程帧不重拍。r4.3又验证了真实RGB输入的编码器RTL回放、XDL原特征入口等价和完整八请求软件工作流。上述均不能冒称两个不同DVP帧是同一输入。

0107只增加工程诊断格式0x32，RGB/灰度/SAT每8像素一组，经**同一次冻结DDR读取**发送。每组先16个原RGB字节，再8个灰度字节和1个SAT字节；尾部k像素为2k+k+1字节。原RGB和灰度/SAT两种模式保留，灰度转换器源码不变。不是9×9残差回传。

## 外部接口真正缺少的证据

已有资料已读：BX72-V1.1用户确认、251215原理图/装配图/引脚表、YT8531C三行丝印、未改硬件/跳线、OV5640V5.0历史照片、ACM5640参考和完整OV5640/YT8531资料。没有要求重传这些文件。

1. 确认V1.1实物适用251215图纸、IO bank的出厂电压和约束电平一致。没有改跳线不能替代实际电压/厂家配置依据。
2. PHY RX/TX延时实际寄存器、RGMII时钟与数据走线差/预算。现有顶层MDIO常高，普通STATUS不读取这些寄存器；不能套用手册默认值当实物测量。保留TJ已有MDIO诊断源，此轮不再给主链增加新控制接口。
3. 当前相机工作模式下PCLK→数据/VSYNC/HREF有效窗口，以及线缆和板线偏斜。旧DVP min0/max2ns无足够出处；RGMII RX/TX缺少外部delay。不能为了通过报告随意补数字。
4. 原CLOCK_DEDICATED_ROUTE覆盖、MIG PLL相关DRC、BRAM异步控制及MIG复位标记问题，按新精确DCP逐条盘点，不降低严重性或批量豁免。0106既有1099条CDC/336条完整DRC作为比较参考。

这些缺口影响“生产发布资格”，不阻止工程验收，也不要求重拍004/005或等待XDL派生图。厂家确认可集中询问上面三组具体事实；无需让YMW猜纳秒约束。

## 最小窗口

新bit与入口全部自检完才开放：下载独立0107一次，运行同一个CMD，按一次KEY2并输入RESET。最多10次工程CAP（同冻结全幅1、八请求灰度8、复位恢复小ROI1）。400/800行仅检验逐请求执行，600行用于诊断；固定gain16=16、LED128，不称为最优曝光，不计训练组，不使用007～010或背面。

窗口中任何一步失败即停止后续CAP，保留原始目录/ZIP和失败原因。OFF ACK只代表控制器回应，不能称物理熄灯测量。实板完成前hardware_tested/release_ready保持false，0105旧09不会切换。
